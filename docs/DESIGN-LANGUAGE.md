# Portfolio design language

更新：2026-10-06

## 核心句

产品先说话，界面负责引导。首页是一个固定身份栏和一面有秩序的不对称产品图墙；详情页把图像、过程和判断按证据顺序展开。

## 版式

- 桌面端左栏固定，右侧内容使用 3 列节奏。
- 首页图块保持清晰的列线，但用 `grid-column` / `grid-row` 改变尺寸：大图与小图交替，形成可预测的不规则感。
- 图块之间使用细缝，产品视觉贴近右侧边界；文字不占据主图中心。
- 700px 以下改为单列，保证图片完整、标题和导航可用。

## 交互语言

- 球状跟随光标是“注意力指示器”，悬停项目时轻微放大，不承担导航信息。
- 开屏黑色遮罩从左向右退出；用户可以点击或按 Enter/Space 进入。
- 项目图块点击进入详情；键盘焦点必须可见。
- 所有动效都必须在 `prefers-reduced-motion: reduce` 下快速结束。

## 内容语言

- 元数据短而可扫描：类别、年份、角色、状态。
- 项目正文回答：做什么、为什么做、做了哪些取舍、如何验证。
- 不使用空泛的“创新”“赋能”等形容词替代设计证据。

## 证据优先级

1. 真实 KeyShot 主图或原型照片。
2. 草图、结构、CMF、测试过程。
3. GLB 交互模型和视频。
4. CSS 占位图只用于开发阶段。

## 可维护约束

- 颜色、字体、间距和动效先改 `src/styles/tokens.css`。
- 项目数据暂时集中在 `src/data/site.ts`；下一阶段迁移到 Astro Content Collections/MDX。
- 参考仓库只作为代码和架构依据，素材必须单独核验许可。
