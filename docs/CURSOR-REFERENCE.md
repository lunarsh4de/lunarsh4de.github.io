# 光标调整 · 2026-11-11

用户指定参考：https://www.martenmalmnas.com/

本次实际检查参考网站的页面样式：默认光标是黑色实心圆，原始资源 24 × 24 像素、常规屏幕显示约 12 像素；链接光标是蓝色圆点，常规屏幕显示约 13 像素。它通过浏览器原生 CSS cursor 切换，没有跟随 DOM 元素，也没有惯性拖尾。

本网站采用同样的交互方式，使用自行编写的 SVG 圆形资源，未复制参考站素材或代码：默认 12 像素黑点，链接及按钮 14 像素蓝点，热点在圆心。细白边让圆点在深色项目图上仍能辨认。

删除了原来的渐变球 DOM、逐帧跟随脚本及旧样式。桌面鼠标启用自定义光标，触屏和系统强制颜色模式使用系统行为；图片放大仍显示放大镜，文本输入仍显示文本光标，禁用控件显示禁止状态。没有持续动画，系统减少动态效果偏好不需要额外运动降级。

原生光标一般不会出现在 Playwright 的网页截图中；核验应检查 cursor 的计算样式、SVG 成功加载、输入与图片操作状态，以及页面导航后状态仍正确，并在真实页面移动鼠标查看效果。
