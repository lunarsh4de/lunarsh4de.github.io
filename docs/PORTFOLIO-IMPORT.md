## 提取与重排

- 直接提取 67 张内嵌图片，处理透明蒙版并生成 WebP 及 480/960 像素衍生版本。没有把 PDF 整页渲染图放入网站。
- 造口贴开口调节、防逆流剖面从 PDF 原始图形提取为 SVG，保持矢量线条与原有视觉。
- `src/data/portfolio-media.json` 保存每张图片对应的页、图片序号、xref、尺寸与版本；`src/data/portfolio-vectors.json` 记录矢量图的原始区域。
- 正文保存在 `src/content/projects/*.md`，标题、段落、列表和图片说明均输出为语义化 HTML。
- 保留“场景 → 方法 → 结构 → 呈现”的纵向阅读方式。桌面有章节导航；手机改为单列，不将 1920 像素画板整体缩小。
- 图片自带尺寸、响应式资源和延迟加载，正文图片避免超出原始像素宽度。点击图片可全屏查看、切换原尺寸并滚动；按 Escape 关闭并返回原焦点。关闭脚本时仍可通过链接打开图片。
- 首页和作品索引使用提取出的作品图，移除原来的三个演示项目。
- 接入后移除了与当前图片作品无关的占位开屏，首页直接展示真实作品；保留身份侧栏与原有导航。

## 文案核对

终端默认编码最初使中文显示为乱码；使用 UTF-8 读取后可正常提取。通过页面渲染参考核对段落、结构与图片。

为网页阅读重组文案，并作以下处理：

- 第 5 页混入的机器人介绍不进入储能页。
- PDF 未提供单项确切年份，元数据标为作品集时间范围 2020–2026，不推断各项目年份。
- 角色不明时使用“项目内容 / 设计方法”，不编造个人职位或贡献归属。
- 第 4 页无具体出处的患者数量、比例，以及“30 天降解”等量化描述不作为已验证事实发布。
- 导航、医疗性能、材料降解与能源性能按概念、规划或待验证内容表述；不把样机过程照片作为已完成性能验证的依据。
- 储能页中的 AI 形态探索、产品风格参考与最终设计均配有对应说明。
- 农场页面展示 PDF 中的界面设计，不宣称预约、支付或住宿服务已经上线；未将来源未核实的二维码作为网站外链。

## 后续编辑

项目元数据在 `src/data/projects/*.json`，正文在同名 Markdown 中；首页顺序与尺寸仍由 `src/data/layout.json` 控制，兼容本地 Composer。

新增图片先放入 `public/images/projects/<slug>/` 并补充媒体清单。Markdown 插件使用清单生成响应式图集、说明和放大链接，缺少对应清单的图片不会自动增强。

重跑提取需要 Python 3、PyMuPDF 和 Pillow：

```powershell
python scripts/extract-portfolio.py '<PDF 路径>'
python scripts/prepare-portfolio-media.py
python scripts/extract-portfolio-vectors.py '<PDF 路径>'
npm run build
npm run preview -- --host 127.0.0.1 --port 4331
# 另一个终端；如使用已有 Chrome，设置 PORTFOLIO_CHROMIUM 为其绝对路径
npm run verify:portfolio
```

`tmp/portfolio/` 中的 PDF 渲染图仅用于校对，已忽略，不发布。
