## 本地同步

在公众号后台为实际出站 IP 添加白名单，不要删除已有配置。网络、VPN 或代理变化可能改变出站 IP。

凭据可以来自 `WECHAT_APP_ID` / `WECHAT_APP_SECRET` 环境变量，或者复用网站目录外的私人配置文件，不要将密钥复制进此仓库：

```powershell
npm run sync:wechat -- --config "D:\Users\81489\Desktop\codex项目\codex输出\公众号\wechat_auto\config.json"
npm run build
```

脚本仅调用 `stable_token` 和 `freepublish/batchget`，不创建草稿、不发表公众号文章。稳定 token 使用 `force_refresh: false`，减少对既有发布工具的影响。默认读取全部分页，每个图文条目均独立导入；使用首次发表时间排序，编辑时间不冒充发布时间。

已有短链接文章在标题与发表时间精确一致时复用原 slug；其余使用规范化原文 URL 的哈希。重复同步且内容无变化时不改数据文件。网络、权限、图片或返回结构异常时，文章数据文件保留上一版本；失败过程中可能留下已验证的未引用图片，不影响当前站点。

日期限制：脚本要求已确认的首次发表日期，不把 `update_time` 当成发布日期。目前官方文档未保证列表响应带有 `content.create_time`；若实际响应缺少此字段，脚本会停止导入，需要从公开原文补齐日期后使用导入模式。尚未完成真实账号的全量接口导入验证。

这是增量归档：公众号删文不会自动删除网站副本。需要同步删除时，明确移除该条网站数据并重新部署。只同步官方 API 实际返回的文章；不要假设接口覆盖公众号历史上的所有群发、转载或特殊内容。

微信视频、音频、小程序卡片等互动组件不转为可执行嵌入，可通过原文入口阅读。正文会移除脚本、事件处理器与内联样式，避免公众号排版挤破移动页面。

## 持续自动同步

现有 GitHub Pages 工作流已预留每小时检查一次，GitHub 调度可能延迟。GitHub 普通托管 runner 的 IP 不固定，不能用本次本地 IP 代替它。

推荐在固定出站 IP 的可信机器上配置 GitHub 自托管 runner（不要向不可信 PR 开放），运行环境需有 Node 20+ 与 npm；也可使用具备固定出站 IP 的其他 runner。将实际固定 IP 加入微信白名单后，在仓库 Settings → Secrets and variables → Actions 配置：

| 类型 | 名称 | 值 |
| --- | --- | --- |
| Secret | `WECHAT_APP_ID` | 自己公众号的 AppID |
| Secret | `WECHAT_APP_SECRET` | 自己公众号的 AppSecret |
| Variable | `WECHAT_SYNC_RUNNER_JSON` | 例如 `["self-hosted", "linux", "wechat-sync"]`，必须匹配实际 runner 标签 |
| Variable | `WECHAT_SYNC_ENABLED` | 验证完成后设为 `true` |

先手动运行 Deploy 工作流，确认同步、构建和 Pages 部署成功，再保留自动检查。关闭 `WECHAT_SYNC_ENABLED` 后定时任务跳过，手动与提交触发的构建仍可使用仓库中的已归档文章。

开启后，每次部署会从公众号重新读取并构建，生成的数据与图片包含在 Pages artifact 中；工作流不自动向仓库提交文章。若需要将全量归档长期保存在 Git 中，在本地同步后单独审查提交。公众号请求失败会阻止该次部署，线上保留上一次成功版本。

## 网站公开接口

`GET /api/articles.json` 是构建时生成的公开 JSON：包括公众号名、最近一次内容变化的同步时间、文章标题、摘要、日期、作者、封面、原文链接和本站路径。它不实时请求微信，也不包含正文 HTML 或密钥。只有网站重新发布后，这个接口才会更新。

## 不使用官方接口时的导入格式

可以从本人已发表原文整理 JSON，运行 `npm run sync:wechat -- --import 路径.json`。这用于明确给定文章的归档，不会枚举账号历史，也不提供自动发现。

```json
[
  {
    "slug": "article-slug",
    "title": "已发表文章标题",
    "author": "作者",
    "publishedAt": "2026-06-23T08:30:00+08:00",
    "sourceUrl": "https://mp.weixin.qq.com/s/真实文章ID",
    "excerpt": "文章摘要",
    "cover": "",
    "contentHtml": "<p>已发表的正文</p>"
  }
]
```

运行 `npm run test:wechat` 验证分页、重复同步、错误保留和内容清理；运行 `npm run build` 验证静态路由。不得把未发表的本地草稿批量导入并当成公众号已发表内容。
